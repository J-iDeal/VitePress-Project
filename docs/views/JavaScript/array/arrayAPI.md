# 数组 API

## 修改原数组

> 修改原数组的方法，会直接修改原数组，而不会返回一个新的数组。

- ### `push()`
  - **用途**: 向数组末尾添加一个或多个元素。
  - **参数**：无

```js
let arr = [1, 2];
arr.push(3); // arr 变为 [1, 2, 3]
```

- ### `pop()`
  - **用途**: 删除数组的最后一个元素。
  - **参数**：无

```js
let arr = [1, 2, 3];
arr.pop(); // arr 变为 [1, 2]
```

- ### `unshift()`
  - **用途**: 向数组开头添加一个或多个元素。
  - **参数**：无

```js
let arr = [2, 3];
arr.unshift(1); // arr 变为 [1, 2, 3]
```

- ### `shift()`
  - **用途**: 删除数组的第一个元素。
  - **参数**：无

```js
let arr = [1, 2, 3];
arr.shift(); // arr 变为 [2, 3]
```

- ### `splice()`
  - **用途**: 添加/删除元素，可指定位置。
  - **参数**: 起始索引、删除的元素个数（可选）、要添加的元素（可选）。

```js
let arr = [1, 2, 3];
arr.splice(1, 1, "a"); // arr 变为 [1, 'a', 3]
```

```js
let arr = [1, 2, 3];
arr.splice(0, 1); // arr 变为 [2, 3]
```

- ### `reverse()`
  - **用途**: 反转数组元素的顺序。
  - **参数**：无

```js
let arr = [1, 2, 3];
arr.reverse(); // arr 变为 [3, 2, 1]
```

- ### `sort()`
  - **用途**: 对数组元素进行排序。
  - **参数**: 排序函数（可选）。

```js
let arr = [3, 1, 2];
arr.sort((a, b) => a - b); // arr 变为 [1, 2, 3]
```

- ### `fill(value, start, end)`

  - **用途**: 用指定值填充数组指定范围的元素。
  - **参数**: 填充值、起始索引、结束索引（可选）。

```js
let arr = [1, 2, 3];
arr.fill(0, 1, 3); // arr 变为 [1, 0, 0]
```

- ### `copyWithin()`

  - **用途**: 复制数组的一部分到同一数组中的另一个位置。
  - **参数**: 目标索引、起始索引、结束索引（可选）。

```js
let arr = [1, 2, 3, 4, 5, 6, 7, 8];
arr.copyWithin(0, 3); // arr 变为 [1,2,3,4,1,2,3,4]
```

## 不修改原数组

> 不修改原数组的方法，不会直接修改原数组，而是返回一个新的数组。

- ### `concat()`

  - **用途**：将多个数组合并为一个数组（不修改原数组）。
  - **参数**：数组

```js
let arr = [1].concat([2], [3]); // [1, 2, 3]
```

- ### `slice()`

  - **用途**：返回数组的一部分，不改变原数组。
  - **参数**：起始索引、结束索引（可选）

```js
let arr = [1, 2, 3, 4, 5];
arr.slice(1, 3); // [2, 3]
```

```js
let arr = [1, 2, 3, 4, 5];
arr.slice(1); // [2, 3 ,4, 5]
```

- ### `join()`

  - **用途**：将数组转换为字符串，并用指定分隔符连接。
  - **参数**：分隔符（可选）

```js
let arr = [1, 2, 3];
arr.join("-"); // "1-2-3"
```

- ### `toString()`

  - **用途**：将数组转换为字符串（等同于 `join()`）。
  - **参数**：无

```js
let arr = [1, 2, 3];
arr.toString(); // "1,2,3"
```

- ### `flat()`

  - **用途**：将嵌套数组“扁平化”为一维数组。
  - **参数**：深度（可选） 使用`Infinity`作为深度参数，可以展开任意深度的嵌套数组

```js
let arr = [1, [2, [3]]];
arr.flat(2); // [1, 2, 3]
```

- ### `flatMap()`

  - **用途**：先映射每个元素，再扁平化结果。
  - **参数**：回调函数

```js
let arr = [1, 2];
arr.flatMap((x) => [x, x * 2]); // [1, 2, 2, 4]
```

- ### `toReversed()`

  - **用途**：将数组反转。
  - **参数**：无

```js
let arr = [1, 2, 3];
arr.toReversed(); // [3, 2, 1]
```

- ### `toSorted()`

  - **用途**：将数组排序。
  - **参数**：对比函数

```js
let arr = [3, 1, 2];
arr.toSorted((a, b) => a - b); // [1, 2, 3]
```
